# Logo do Projeto

Adicione o arquivo da logo aqui. O arquivo deve ser nomeado como `logo.png` ou `logo.svg`.

**Exemplo de arquivos suportados:**
- `logo.png` - Imagem PNG
- `logo.svg` - Imagem SVG (recomendado para escalabilidade)
- `logo.jpg` - Imagem JPG

A logo será automaticamente importada e exibida na página de login e no dashboard.
